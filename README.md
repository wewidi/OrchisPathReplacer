# OrchisPathReplacer

Orchisランチャーの設定ファイル（.ocs）内に含まれる
フォルダパスの一部を一括置換する非公式補助ツールです。

## 主な機能

- .ocsファイルの選択
- 置換元パス・置換先パスの指定
- ws: 文字列項目内のパス置換
- ItemID=bn: 内部に含まれるパス情報の解析
- 更新前バックアップの自動作成
- 文字コードとBOM有無を維持して保存

## 注意

ItemID=bn: は通常の文字列ではなく、
Windows Shell の ITEMIDLIST / PIDL 系の情報を含むため、
完全な互換性を保証するものではありません。

使用前には必ずバックアップを確認してください。
