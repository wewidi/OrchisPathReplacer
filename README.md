# OrchisPathReplacer

Orchisランチャーの設定ファイル（.ocs）内に含まれるフォルダパスを一括置換するための非公式補助ツールです。

## 概要

PC移行、ドライブ構成変更、開発フォルダ移動などで、Orchisの登録パスをまとめて変更したい場合に使用します。

## 主な機能

- `.ocs` ファイルの選択
- 置換元パス・置換先パスの指定
- `ws:` 文字列項目内のパス置換
- 置換前プレビュー
- 更新前バックアップの自動作成
- 元ファイルの文字コード・BOM有無を維持して保存

## 注意

`ItemID=bn:` は通常の文字列ではなく、Windows Shell の PIDL / ITEMIDLIST 系の情報を含むため、単純な文字列置換は危険です。

本ツールは安全性を優先し、バックアップ作成とプレビュー確認を前提にしています。
